## 🛠️ High-Impact Framework: Sistema de Limpieza de Datos (Flujo Optimizado)

Este sistema es mi firma técnica: un framework modular en Python diseñado para la sanitización, normalización y transformación estadística de datos de grado empresarial.

### 🚀 Valor de Negocio (Enterprise Grade)
* **Reliability:** Establece una base de datos 100% confiable para reportes C-Level.
* **Efficiency:** Reducción drástica en tiempos de limpieza manual mediante el uso de mis **Kits de Unicidad y Transformación**.
* **Scalability:** Arquitectura preparada para integrarse con **dbt, Snowflake y BigQuery**.

---

## 📦 Arquitectura del Sistema (System Architecture)

El framework se compone de tres módulos core:
* **`structure_cleaning.py`**: Text standardization and datetime parsing.
* **`uniqueness_handler.py`**: **Fuzzy Matching** logic to fix typos and deduplicate records.
* **`statistical_transformation.py`**: **Outlier detection (IQR)** and missing value imputation.
